# Cube Studio

실행: index.html을 브라우저로 엽니다. 서버나 설치는 필요하지 않습니다.

```text
cube-studio/
├─ index.html                 실행 화면
├─ src/                       프로그램 코드
│  ├─ app.js                  큐브와 회전
│  ├─ algorithm.js            직접 입력 실행
│  ├─ cases.js                케이스 선택·재생
│  └─ export.js               노션 카드
├─ data/
│  ├─ beginner/
│  │  ├─ cases.json           원본: 초급 해법 109개 케이스
│  │  └─ cases.bundle.js      자동 불러오기용 생성 파일
│  └─ f2l/
│     ├─ cases.json           원본: F2L 41개 케이스
│     └─ cases.bundle.js      자동 불러오기용 생성 파일
├─ docs/
│  ├─ JSON-format.md          데이터·표시 규칙
│  ├─ beginner-guide.md       초급 단계 설명
│  └─ F2L.md                  F2L 분류와 검증 기준
└─ tools/
   └─ build-case-bundle.cjs   JSON → 앱용 데이터 생성
```

각 cases.json 파일 하나는 해법 컬렉션 전체입니다. 초급 해법과 F2L은 학습 목록에서 독립된 토글로 표시됩니다. 화면의 단계·케이스 트리는 실제 폴더와 일대일 대응하지 않습니다.

데이터를 수정할 때는 해당 data 하위 폴더의 cases.json을 편집하고 아래 명령을 실행합니다.

```text
node tools/build-case-bundle.cjs
```

이후 index.html을 새로고침합니다. 생성 파일은 직접 수정하지 않습니다. 데이터 형식과 역할 정의는 docs/JSON-format.md를 참고하세요.

실전 모드: 왼쪽에서 셔플을 누르면 완성 상태에 인접 회전의 축이 겹치지 않는 20수를 무작위 적용합니다. 첫 사용자 회전부터 시간을 재고, 여섯 면 완성 시 타이머와 회전을 잠급니다. 큐브 아래 버튼은 바깥층·두 층·중앙층·전체 회전과 프라임·2회전을 지원합니다. 새 셔플로 다시 도전할 수 있습니다. 각 모드의 큐브 상태는 탭이 열려 있는 동안 별도로 유지됩니다.

실전 키보드: F=L', D=L, J=R, K=R', G=F, H=F', R=U', U=U, B=f, N=f', E=u', I=u, X=D, .=D', S=B', L=B. 키를 길게 눌러도 반복하지 않으며 빠른 연속 입력은 순서대로 실행합니다.



실전 전체 회전: 왼쪽 방향키 = y, 오른쪽 방향키 = y'.






실전 뒷면 두 층: A = b', 세미콜론(;) = b. 콜론(:)과 같은 물리 키이며 Shift 없이 사용합니다.



추가 키: Z=d, /=d', C=l, V=l', M=r, 쉼표(,)=r', G=F, H=F'. T·Y 연결은 제거했습니다.







실전의 키보드 튜토리얼은 26개 키를 순서대로 연습합니다. 시범 90도 회전 후 표시된 키를 세 번 눌러 한 바퀴를 완성하면 통과합니다. 통과 후 다음 키로 자동 진행하며, 타이머·실전 수에는 포함하지 않습니다. 종료하면 시작 전 큐브 상태로 돌아옵니다.

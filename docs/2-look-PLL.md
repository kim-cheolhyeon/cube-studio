# 2-look PLL

OLL을 마친 상태에서 마지막 층의 위치를 두 단계로 맞춥니다.

윗면이 모두 노랑인 상태에서 시작합니다. U 노랑 / D 흰색 / F 초록 / R 주황 기준이며, 큐브 전체를 돌려 그림의 배치와 방향을 맞춘 뒤 실행합니다.

## 1. 코너 위치 맞추기 · 2개

| 케이스 | 판별 | 목표 |
|---|---|---|
| 인접 코너 교환 | 이웃한 코너 2개 교환 · 같은 색 코너 쌍은 L면 | 코너 위치 정렬 |
| 대각 코너 교환 | 대각 코너 2개 교환 · 같은 색 코너 쌍 없음 | 코너 위치 정렬 |

코너 쌍은 한 옆면 윗줄의 양 끝 스티커를 뜻합니다. 실제 큐브에서는 U 정렬 후 배치를 판단합니다. 이미 코너가 맞으면 엣지 단계로 넘어갑니다. 이 단계에서 엣지 위치는 바뀔 수 있습니다.

## 2. 엣지 위치 맞추기 · 4개

| 케이스 | 판별 |
|---|---|
| 3개 순환 · Ua | 맞은 엣지 1개 · 나머지 세 개 순환 |
| 3개 순환 · Ub | 맞은 엣지 1개 · Ua와 반대 방향 |
| 마주 보는 엣지 교환 · H | 맞은 엣지 0개 · 앞뒤, 좌우 교환 |
| 이웃한 엣지 교환 · Z | 맞은 엣지 0개 · 이웃한 두 쌍 교환 |

맞은 엣지는 옆면 윗줄 중앙 스티커가 해당 면 중앙색과 일치하는 조각입니다. Ua·Ub의 고정 엣지 방향은 각 케이스 설명과 큐브를 기준으로 합니다. 옆면 색의 이동 방향을 보며 두 순환을 비교하면 됩니다.

## 재생과 표시

- 코너 케이스는 코너 위치까지만, 엣지 케이스는 큐브 완성까지 재생합니다.
- 코너 단계는 첫 두 층·중앙·윗면 엣지의 노랑 38칸을 protected, 목표 코너 12칸을 focus로 표시합니다. 엣지 옆면 4칸은 검정이며 위치를 보존할 필요가 없습니다.
- 엣지 단계는 첫 두 층·중앙·완성한 코너 46칸을 protected, 목표 엣지 8칸을 focus로 표시합니다.
- 윗면 방향과 첫 두 층은 공식 종료 후 유지됩니다. 회전 도중에는 잠시 흐트러질 수 있습니다.

## 데이터와 공식

원본은 data/pll2/cases.json, 생성 파일은 data/pll2/cases.bundle.js입니다. 편집 후 node tools/build-case-bundle.cjs를 실행합니다. 검사 명령은 node tools/check-pll2.cjs입니다.

공식은 Feliks Zemdegs·Andy Klise의 [CubeSkills 4 Look Last Layer](https://cubeskills.com/uploads/pdf/tutorials/4-look-last-layer.pdf)를 참고했습니다. 대각 코너 공식에는 마지막 U, Z 공식에는 마지막 U2 정렬을 포함하여 현재 앱의 기준 면에 정확히 맞춰 끝나게 했습니다. M은 가운데 층 회전입니다.

상태는 합법적인 회전으로 생성했습니다. 완성 상태를 별도 케이스로 추가하지 않았습니다. 각 공식의 교환 조각 수, 인접·대각 구분, 첫 두 층과 윗면 방향 보존, 재생·되돌리기·초기화 및 엣지 배치가 다른 코너 케이스를 검사합니다.

# 2-look OLL

F2L을 마친 뒤 마지막 층의 방향을 두 단계로 맞춥니다. U 노랑 / D 흰색 / F 초록 / R 주황을 기준으로 합니다.

## 1. 십자가 만들기 · 3개

윗면 중앙과 엣지만 봅니다. 코너는 이 단계에서 무시합니다.

| 케이스 | 시작 배치 | 목표 |
|---|---|---|
| 가로선 | 노랑 엣지가 왼쪽·오른쪽 | 노랑 십자가 |
| ㄱ자 | 노랑 엣지가 뒤쪽·왼쪽 | 노랑 십자가 |
| 점 | 노랑 엣지 없음 | 노랑 십자가 |

이미 십자가가 있으면 두 번째 단계로 넘어갑니다. 점 케이스는 십자가가 될 때까지 연결한 공식을 재생합니다.

## 2. 코너 방향 맞추기 · 7개

십자가가 만들어진 상태에서 윗면의 노랑 코너 수로 구분합니다. 같은 수라도 옆면 노랑 스티커의 방향이 다릅니다. 화면에 표시된 배치와 방향을 맞춘 뒤 실행하세요.

| 윗면 노랑 코너 | 케이스 |
|---|---|
| 1개 | 피시 · 수네 / 피시 · 역수네 |
| 2개 | U형 · 헤드라이트 / T형 / L형 |
| 0개 | 파이형 / H형 |

이미 윗면이 모두 노랑이면 OLL은 끝났습니다. 그다음 PLL로 조각의 위치를 맞춥니다. 옆면 색이 서로 맞지 않아도 OLL을 할 수 있습니다.

## 색 표시와 재생

- 십자가 단계: 첫 두 층과 중앙 34칸을 protected, 목표 엣지 8칸을 focus로 지정합니다. 코너는 검정입니다.
- 코너 단계: 첫 두 층·중앙·위층 엣지 42칸을 protected, 목표 코너 12칸을 focus로 지정합니다.
- 첫 두 층은 공식 종료 후 색과 위치가 유지됩니다. 코너 단계의 십자가는 노랑이 위를 향하는 상태를 유지하며 엣지의 위치는 바뀔 수 있습니다.
- 재생은 선택한 단계의 목표까지 실행합니다. 십자가 케이스를 재생한 뒤 코너까지 자동으로 풀지는 않습니다.

## 데이터와 검증

원본: data/oll2/cases.json. 자동 불러오기용 파일: data/oll2/cases.bundle.js.

기존 formatVersion 3과 categoryPath·protected·focus·solutions를 사용합니다. 각 상태는 합법적인 회전으로 생성했으며 도형 이미지에서 색을 임의로 칠하지 않았습니다. 전체 완성 상태 예시는 목록에 추가하지 않았습니다.

수정 후 node tools/build-case-bundle.cjs로 번들을 생성합니다. node tools/check-oll2.cjs는 세 엣지·일곱 코너 방향 패턴의 중복, 목표 달성, 첫 두 층 보존, 재생·되돌리기·초기화와 마지막 층 위치가 다른 변형을 검사합니다.
